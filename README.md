# Sales Data Exploratory Data Analysis (EDA)

This project is an Excel-based Sales Data Exploratory Data Analysis project.

The goal was to analyze a sales dataset, identify data-quality issues, calculate important sales metrics, explore sales patterns, and communicate useful findings from the data.


## Objectives

The main objectives of this project were to:

- Understand the structure of a sales dataset
- Check the dataset for data-quality issues
- Identify missing values and inconsistencies
- Check for duplicate records
- Calculate basic sales metrics
- Analyze sales by category and country
- Analyze sales over time
- Explore the relationship between discounts and sales
- Create charts to communicate findings
- Develop analytical thinking and data interpretation skills

---

##  Dataset

The dataset contains **600 sales orders**.

### Columns

| Column | Description |
|---|---|
| Order_ID | Unique identifier for each order |
| Order_Date | Date the order was placed |
| Customer_ID | Identifier for the customer |
| Country | Country where the order was made |
| Region | Sales region |
| Product | Product purchased |
| Category | Product category |
| Quantity | Number of units purchased |
| Unit_Price | Price per unit |
| Sales | Recorded sales revenue |
| Discount | Discount applied to the order |
| Payment_Method | Method used to pay for the order |

- Checking for duplicate records
- Checking for inconsistent capitalization
- Checking for invalid quantities
- Checking for unusual discounts
- Checking for missing prices
